# FX-02 — Killshot fires on whatever is left

**Size:** S · **Depends on:** — · **Branch:** `dev`
**Design refs:** JG-31a/b and LV-02d (in `git log`)

## Goal

Killshot auto-casts when its best line holds 3 bodies, or holds every body within its reach.

Owner playtest, 2026-11-05: with only Mossguards left, Killshot never fired. Cause: `Killshot.asset`'s trigger is `EnemiesInAcquireRange AtLeast 3`, and one or two enemies never meet it.

The existing 5-argument `TryPick` stays and forwards.

## Behaviour

1. `CanCast` is true only when the picked line's `hits >= Math.Min(MinHits, inReach)`, where `inReach` counts living bodies within `Length` (XZ) of the player. The existing conditions (not winding up, alive, not charging, a line exists) still apply.
2. 3 or more bodies on one line → castable (unchanged).
3. 1 or 2 bodies in reach, all on the picked line → castable.
4. 3 bodies in reach, the best line holds 2 → not castable.
5. A body beyond `Length` never raises the bar.
6. `CanCast` allocates nothing.
7. The skill's trigger is `EnemiesInAcquireRange AtLeast 1`; the Skills screen's trigger text follows from `TriggerText` with no new LocKey.
